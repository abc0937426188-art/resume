## 本地預覽
使用 Python 內建 HTTP 伺服器即可預覽：
```bash
cd resume-website
python3 -m http.server 8000
```
然後在瀏覽器開啟 `http://localhost:8000`。

## 部署至 GitHub Pages
1. 在本地儲存庫提交變更：
   ```bash
   git add .
   git commit -m "feat: upgrade to blue-purple-pink theme, add Taiwan top meme interaction and particle animations"
   git push origin main
   ```
2. GitHub Pages 會自動重新部署更新！
